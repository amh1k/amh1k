## Selected Work

### [Mithril Tiles](https://github.com/amh1k/mithril-tiles)

A server-authoritative, real-time multiplayer drawing and guessing game built
with Go, WebSockets, Next.js, and PostgreSQL.

* Concurrency-safe room and game-state management
* Authenticated WebSocket connections using short-lived, single-use tickets
* Next.js backend-for-frontend layer for secure session handling
* PostgreSQL persistence, integration testing, and race-tested realtime components

### [Keepalive Monitoring](https://github.com/amh1k/keepalive-monitoring)

A self-hosted uptime monitoring platform with queue-backed HTTP checks,
incident tracking, latency analysis, TLS inspection, and alerting.

* Redis and BullMQ-based background job processing
* Retry handling, heartbeat processing, and monitoring schedules
* Incident lifecycle and historical latency tracking
* Discord alerts and certificate-expiration inspection

### [ScadrialAPI](https://github.com/amh1k/ScadrialAPI)

A production-minded REST API built with Go and PostgreSQL.

* Token-based authentication and role-based authorization
* Optimistic locking and permission-based access control
* Rate limiting, graceful shutdown, panic recovery, and structured logging
* Database migrations, Swagger documentation, metrics, and E2E tests

### [Durin's Code](https://github.com/amh1k/DurinsCode)

A programming language and execution environment implemented in C++ with a
browser-based WebAssembly playground.

* Lexer and recursive-descent parser
* Semantic analysis and three-address code generation
* JSON bytecode format and stack-based virtual machine
* Automated tests covering the compiler and runtime pipeline
